🚀 إعداد الخدمات المطلوبة

اتبع الخطوات التالية لربط جميع الخدمات المطلوبة:

1. ChatGPT API

غير متصل
اذهب إلى platform.openai.com
سجل حساب جديد أو سجل دخول
اضغط على "API Keys" من القائمة الجانبية
اضغط "Create new secret key"
انسخ المفتاح والصقه هنا:
إضافة رصيد

2. WhatsApp Business API

غير متصل
اذهب إلى Twilio (الأسهل)
سجل حساب مجاني
فعّل WhatsApp Sandbox للتجربة
احصل على Account SID و Auth Token
اربط رقم WhatsApp Business

3. قاعدة البيانات (Supabase)

غير متصل
اذهب إلى supabase.com
سجل بحساب GitHub أو بريد إلكتروني
أنشئ مشروع جديد (New Project)
انتظر إنشاء قاعدة البيانات (دقيقتين)
انسخ URL و anon key من الإعدادات

4. استضافة الموقع (Vercel)

جاهز للنشر
اذهب إلى vercel.com
سجل بحساب GitHub
اضغط "Import Project"
ارفع ملفات المشروع
انتظر النشر (دقيقة واحدة)
